# learn-obsidian

Self-paced Obsidian course (lessons in Russian), grounded in two real projects: an LLM-wiki of legacy VB6 business logic (Kolnatun) and a personal media wiki.

- `MISSION.md` - why and what success looks like
- `lessons/` - one HTML file per lesson (open locally in a browser)
- `reference/` - cheat sheets and glossary
- `assets/` - shared CSS and JS components (quiz, search simulator)
- `learning-records/` - progress log
- `RESOURCES.md` - sources and communities
