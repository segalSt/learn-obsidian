# Practice vault

Учебное хранилище для уроков. Здесь можно ломать что угодно — это не рабочий проект.

Открыть: Obsidian → Open folder as vault → эта папка (`practice-vault`).

- `Медиатека/` — пример из личной медиа-вики (фильмы, книга).
- `Люди/` — люди, на которых ссылаются заметки (урок 0002: `aliases`).
- `Kolnatun/` — упрощённые копии страниц из `calculators/shared`.

`Медиатека/Фильмы/Солярис (1972).md` — образец со свойствами всех типов (урок 0002).
