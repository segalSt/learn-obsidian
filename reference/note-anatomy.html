Заметка: части и синтаксис

Заметка = файл .md в папке хранилища. Три части: свойства, заголовки, текст.

Скелет файла

---
type: film                    ← свойство: имя: значение
year: 1979                    ← число
director: "[[Тарковский]]"    ← ссылка в свойстве — в кавычках
tags:                         ← список
  - фантастика
---
# Сталкер (1979)              ← заголовок 1
## Мой комментарий            ← заголовок 2
Текст, **жирный**, *курсив*, [[ссылка]].
%% комментарий: виден только при редактировании %%

Синтаксис текста

#ПишешьПолучаешь
1# … ######заголовок уровня 1–6
2**жирный** / *курсив*выделение
3- пункт / 1. пунктсписок
4- [ ] задача / - [x] готовочекбокс
5> текстцитата
6`код`, блок из ```код
7[[Заметка]]ссылка на заметку
8%% … %%комментарий

Виды

#ВидКак попасть
1Reading viewCtrl+E из редактирования
2Live PreviewSettings → Editor → Default editing mode
3Source modeтам же

Свойства: быстрые факты

#Факт
1Добавить свойство: Ctrl+; или набрать --- в первой строке
2Типы: Text, List, Number, Checkbox, Date, Date & time, Tags
3Встроенные: tags, aliases, cssclasses
4Имя свойства в заметке — одно (нельзя два tags)
5Вложенные свойства не поддерживаются в таблице свойств — смотри в Source mode
