Горячие клавиши

Клавиши, которые используют уроки курса (Windows). Полный список и смена клавиш — Settings → Hotkeys.

Где посмотреть все клавиши

#ГдеЧто там
1Settings → Hotkeysвсе команды и их клавиши; есть строка поиска. Поменять: + рядом с командой → нажми сочетание → Save.[hotkeys]
2Command palette (Ctrl+P)все команды; клавиша команды показана рядом с ней.[команды] Не помнишь клавишу — ищи команду здесь.
