Шпаргалка

Свойства

Тип принадлежит имени свойства во всём хранилище. Ссылки — в кавычках. Даты — YYYY-MM-DD.

Типы

status: смотрел                    ← Text
director: "[[Тарковский]]"         ← Text со ссылкой: кавычки обязательны
cast:                              ← List: каждое значение через "- "
  - Донатас Банионис
  - Наталья Бондарчук
year: 1972                         ← Number: всё значение — число
watched: false                     ← Checkbox: true / false / пусто
added: 2026-10-06                  ← Date: YYYY-MM-DD
last_opened: 2026-10-06T21:30:00   ← Date & time
tags:                              ← Tags: только у tags, без #, без пробелов внутри тега
  - кино/советское

Встроенные свойства

#ИмяТипЗаметка
1tagsTagsбез #, без пробелов внутри тега, не только цифры, / = вложенный
2aliasesListдругие имена для ссылок: [[Тарковский|Tarkovsky]]
3cssclassesListоформление CSS

Устарели с 1.9: tag, alias, cssclass.
