Поиск и фильтр графа

Один язык для поиска (Ctrl+Shift+F) и для Graph view → Filters → Search files.

Операторы

#ОператорПримерЗначит
1path:path:shared/entitiesпуть содержит строку
2file:file:glossaryимя файла содержит строку
3content:content:"nek_zikui"только текст заметки
4tag:tag:#todoесть тег
5[prop][used_by]свойство есть
6[prop:value][kind:method]свойство равно значению
7[prop:null][used_by:null]свойство пустое
8line:( )line:(CalcNek mone)слова в одной строке
9section:( )section:(Relation MasHazmai)слова в одном разделе
10/regex//R-AcademicEnd-0\d\d/регулярное выражение
Два правила. Пути — через /, не \. Звёздочка * не шаблон: path: и file: уже ищут часть строки.

Логика

#ПишешьЗначит
1a ba и b
2a OR ba или b
3-aубрать a
4(a OR b) -cскобки группируют
5"два слова"точная фраза
