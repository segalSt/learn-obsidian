Файл .base

filters:            # All views
  and:
    - file.inFolder("Медиатека")
    - 'type == "film"'      # текст внутри — условие в одинарных кавычках
formulas:
  age: "today().year - year"
properties:
  formula.age:
    displayName: "Лет"
views:
  - type: table             # table | list | cards | kanban | map
    name: "Всё"
    filters: { ... }        # This view
    order: [file.name, year, formula.age]
    groupBy: { property: note.type, direction: ASC }
    summaries: { year: Min }
    limit: 10
Ловушки. = — это Dataview, в Bases ==. AND / OR — Dataview, в Bases && / || или списки and: / or:. contains(x, "a") и length(x) — Dataview, в Bases x.contains("a"), x.length. Backspace по выделенным ячейкам стирает свойства в заметках; Kanban при перетаскивании меняет свойство (по file.folder — переносит файл).
