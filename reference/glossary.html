Слова, которые используют все уроки. Термины Obsidian — по-английски, как в интерфейсе.

#ТерминЗначение
1Vault (хранилище)Папка с .md файлами, открытая в Obsidian. Для Kolnatun — kolnatun-context-2.0.
2Note (заметка)Один .md файл.
3Properties (свойства)Поля в начале заметки между ---, напр. used_by: [AcademicEnd]. [справка]
4Graph viewКарта заметок (точки) и ссылок (линии). Ctrl+G.
5Local graphГраф вокруг одной заметки.
6Filter (граф)Строка поиска в Graph view → Filters; оставляет только совпавшие заметки.
7Group (граф)Запрос + цвет: красит совпавшие точки.
8BacklinksКто ссылается на эту заметку.
9AttachmentНе-.md файл в хранилище (.mmd, .html, картинки).
10DataviewПлагин: запросы-таблицы по свойствам (TABLE … FROM … WHERE). [docs]
11BasesВстроенные таблицы по свойствам, без кода. [справка]
12Layer (слой)Наш термин: результат / исходник / процесс / порт. Сейчас — по папкам; позже — свойство layer.
13Entity (сущность)Наш термин: страница части исходного кода в shared/entities. Контейнер (файл) > член (метод/функция).
14Concept (понятие)Наш термин: термин, общий для 2+ калькуляторов, в shared/concepts.
15LLM wikiПаттерн: агент пишет и поддерживает страницы, человек читает в Obsidian. Операции: ingest, query, lint.
16FrontmatterБлок свойств в начале файла между двумя строками --- (формат YAML).
17Reading viewВид для чтения: текст без значков Markdown. Ctrl+E.
18Live PreviewРежим редактирования: оформленный текст, значки видны только в строке с курсором.
19Source modeРежим редактирования: файл как есть, все значки видны.
20Excluded filesSettings → Files & Links: папки, скрытые во всём хранилище (поиск, граф, unlinked mentions). Не путать с фильтром графа.
21.obsidianСкрытая папка в корне хранилища: настройки, горячие клавиши, плагины. Не заметки.
22YAMLТекстовый формат «имя: значение», в котором записан блок свойств.
23Property type (тип свойства)Какие значения бывают у свойства: Text, List, Number, Checkbox, Date, Date & time, Tags. Один тип на имя во всём хранилище. [справка]
24List (тип)Несколько значений, каждое с новой строки через - . Напр. used_by.
25Checkbox (тип)true / false; пусто = не определено.
26TagsСвойство tags: список тегов без # и пробелов; / делает вложенный тег. [справка]
27AliasesСвойство aliases: другие имена заметки, видны в подсказках ссылок. [справка]
28All properties (Properties view)Список всех свойств хранилища и их типов; сортировка, переименование везде, поиск по клику. [справка]
29Command paletteСписок всех команд Obsidian, Ctrl+P. [справка]
30Properties in documentSettings → Editor: показывать свойства таблицей (Visible), скрыть (Hidden) или как YAML (Source).
31Nested property (вложенное свойство)Свойство внутри свойства. Obsidian не поддерживает.
32Nested tag (вложенный тег)Тег с уровнями через /: кино/советское. Поиск tag:кино находит и вложенные. [справка]
33Tags viewСписок всех тегов хранилища; вложенные показаны под родителем. Ctrl+P → tags.
