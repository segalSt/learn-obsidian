Шпаргалка

Ссылки и backlinks

Внутри ссылки: / — папки, # — заголовок, #^ — блок, | — текст, ! — встроить.

Синтаксис

[[Сталкер (1979)]]                          ← заметка (.md можно не писать)
[[Тарковский|Андрея Тарковского]]           ← заметка, другой текст
[[Сталкер (1979)#Мой комментарий]]          ← заголовок
[[#Связи]]                                  ← заголовок этой заметки
[[calc-logic#Шаги#Шаг 10]]                  ← подзаголовок
[[Пикник на обочине#^final-quote]]          ← блок
![[Пикник на обочине#^final-quote]]         ← встроить блок
[credit points](concepts/credit-points.md)  ← Markdown-формат; пробел = %20

Метка блока

#Правило
1^ + латиница, цифры, дефис: ^final-quote
2абзац — пробел и метка в конце строки; пункт списка — в конце пункта
3таблица, список, цитата — метка отдельной строкой, пустые строки до и после

Поиск при вставке

#НабираешьИщет
1[[заметки
2[[#заголовки этой заметки
3[[## словозаголовки во всём хранилище
4[[^^словоблоки во всём хранилище

Панели

#Панель → разделПоказывает
1Backlinks → Linked mentionsкто ссылается на открытую заметку
2Backlinks → Unlinked mentionsгде её имя написано без ссылки; кнопка Link превращает в ссылку
3Outgoing links → Linksкуда ссылается открытая заметка
4Outgoing links → Unlinked mentionsтекст в ней, совпадающий с именем / псевдонимом другой заметки

Нельзя / помни

#Правило
1в именах заметок нет # | ^ : %% [[ ]]
2переименовывать в Obsidian; Settings → Files and links → Automatically update internal links
3ссылка на несуществующую заметку допустима; клик её создаёт
4ссылка в свойстве (director: "[[Тарковский]]") видна в Backlinks → Linked mentions — проверено опытом 2026-10-07; в справке не описано. Обновление при переименовании — ещё проверить (урок 0003, шаг 8)
