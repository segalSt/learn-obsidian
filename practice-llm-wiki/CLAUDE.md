# Схема медиа-вики (schema)

Ты — агент, который ведёт эту вики. Человек читает её в Obsidian.
Хранилище (vault) = эта папка. Учебный пример к уроку 0008 курса learn-obsidian.

## Слои

| # | Папка | Что там | Кто пишет |
|---|---|---|---|
| 1 | `raw/` | источники: мои заметки после просмотра, статьи (Web Clipper) | человек; агент только читает, **никогда не меняет** |
| 2 | `wiki/` | страницы вики | только агент |
| 3 | `CLAUDE.md` | эта схема | человек и агент вместе |

Плюс два служебных файла в корне: `index.md` (каталог) и `log.md` (журнал).

## Страницы

| # | Папка | Страница | `type` |
|---|---|---|---|
| 1 | `wiki/Фильмы/` | один фильм, имя `Название (год)` | `film` |
| 2 | `wiki/Книги/` | одна книга | `book` |
| 3 | `wiki/Люди/` | режиссёр, автор, актёр | `person` |
| 4 | `wiki/Понятия/` | тема, общая для 2+ страниц | `concept` |

## Свойства

| # | Свойство | Тип | На | Значение |
|---|---|---|---|---|
| 1 | `type` | Text | все | см. таблицу страниц |
| 2 | `year` | Number | film, book | год выхода |
| 3 | `director` | Text | film | ссылка в кавычках: `"[[Тарковский]]"` |
| 4 | `authors` | List | book | ссылки в кавычках |
| 5 | `based_on` | Text | film | ссылка на книгу |
| 6 | `status` | Text | film, book | `смотрел` / `хочу посмотреть` / `читал` / `хочу прочитать` |
| 7 | `sources` | List | все в `wiki/` | ссылки на файлы `raw/`, из которых взяты факты |
| 8 | `aliases` | List | person | другие написания имени |
| 9 | `tags` | Tags | film, book | без `#`; жанр через `/`: `кино/фантастика` |

Правила урока 0002: одно имя = один тип; списки через `- `; без вложенных свойств; даты `YYYY-MM-DD`.

## Текст страницы

- Первая строка после свойств: `# Название`.
- Каждый факт — из файла `raw/`; в конце страницы раздел `## Источники` со ссылками `[[…]]` на них.
- Упоминание другой страницы вики — всегда ссылка `[[…]]`.
- Противоречие между источниками — не выбирать, а записать оба в раздел `## Противоречия`.

## Операции

**Ingest** (человек: «ingest raw/…»): прочитать источник → кратко обсудить с человеком → создать или обновить страницы → добавить строку в `index.md` → добавить запись в `log.md`.

**Query** (человек задаёт вопрос): сначала прочитать `index.md`, потом нужные страницы; ответ со ссылками. Ценный ответ — предложить сохранить как страницу в `wiki/Понятия/`.

**Lint** (человек: «lint»): только отчёт, без правок. Искать: страницы без входящих ссылок (orphans), ссылки на несуществующие страницы, страницы, которых нет в `index.md`, свойства не по этой схеме, противоречия.

## log.md

Только дописывать в конец. Формат заголовка: `## [YYYY-MM-DD] операция | что`.
