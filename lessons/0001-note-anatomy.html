Анатомия заметки

Каждая заметка — обычный текстовый файл из трёх частей. Научишься видеть эти части и переключать вид заметки.

Цель урока. Открыть любую заметку — из медиатеки или из Kolnatun — и за 10 секунд показать: где свойства, где заголовки, где текст.

1. Хранилище и заметка

Vault (хранилище) — обычная папка на диске. Заметка — обычный файл .md (Markdown, простой текст) в этой папке или её подпапках.[хранение] Никакой базы данных: открой файл в Блокноте — увидишь то же самое, только без оформления.

В корне хранилища Obsidian создаёт скрытую папку .obsidian — там настройки этого хранилища: горячие клавиши, тема, плагины.[хранение] Заметки там не лежат.

2. Три части заметки

#ЧастьКак выглядит в файлеЗачем
1Свойства (properties)в самом начале, между двумя строками ---; каждая строка имя: значениеданные о заметке: год, статус, где лежит, кто использует. По ним работают поиск, Bases, Dataview.[свойства]
2Заголовкистрока с # в начале: # — уровень 1, ## — уровень 2, … до 6[синтаксис]скелет заметки; на заголовок можно сослаться
3Текст (body)всё остальное: абзацы, списки, таблицы, ссылки [[…]]содержание

Внутри текста есть ещё мелочь, которую стоит узнавать: %% … %% — комментарий, виден только при редактировании.[синтаксис]

3. Три вида одной заметки

#ВидЧто видишь
1Reading view (чтение)готовый текст без значков Markdown
2Live Preview (редактирование)оформленный текст, значки видны только в строке, где курсор
3Source mode (редактирование)файл как есть, все #, **, ---

Ctrl+E переключает чтение ⇄ редактирование. Какой режим редактирования (Live Preview или Source) — задаётся в Settings → Editor → Default editing mode.[виды] Для изучения анатомии удобнее Source mode: видно всё.

4. Практика: что это за строка?

Это заметка Сталкер (1979).md из учебного хранилища — так, как она лежит в файле (Source mode). Для каждой строки нажми, к какой части она относится. Ответ виден сразу.

Теперь та же анатомия в твоём Kolnatun: страница SetErrorObject.md — свойства type, kind, source, line, used_by между ---, потом заголовок # SetErrorObject, потом текст и таблица. Устроено одинаково.

5. Проверь себя

По памяти, не листая вверх.

6. Теперь в настоящем Obsidian

  1. Открой учебное хранилище: в Obsidian — значок хранилищ слева внизу → Open folder as vault → C:\_repos\GitHub\segal.st\teach\learn-obsidian\practice-vault. Рабочий Kolnatun не трогаем.
  2. Открой Медиатека/Фильмы/Сталкер (1979). Свойства показаны таблицей сверху — это Live Preview.
  3. Нажми Ctrl+E — Reading view. Ещё раз — обратно. Найди, куда пропал комментарий %% … %%.
  4. Settings → Editor → Default editing mode → Source mode. Открой заметку заново: теперь видно --- и все строки свойств как в упражнении. Потом верни Live Preview, если так удобнее.
  5. Открой Kolnatun/SetErrorObject и назови вслух три части.
